# Report template

Use this shape for the Phase 5 report, in chat (`full`) or in `gerrit-reviewbot-fix-plan.md` (`audit`).

```markdown
# gerrit-reviewbot-fix plan — change <number>

## Provenance
- Change: <number> · <subject>
- Project: <project>
- Target branch: <target> (from Gerrit, not from the local branch)
- Remote: <remote> · Base: `merge-base HEAD <remote>/<target>` = <sha>
- Local branch: <name or "detached"> · Local head: <sha>
- Patchset reviewed: <n> (current: <n>) · Revision match: yes
- Tree: clean | dirty (<files>)
- Generated: <date>

## Summary
- Bot account: <author name as it appears>
- Bot reviewed patchset: <n> of <current n> — current | behind (findings may be incomplete)
- Bot comments: <n> total, <n> unresolved, <n> after collapse (patchset-level chatter dropped)
- Live: <n> · Stale: <n> · Wrong: <n> · Blocked: <n>
- Human comments: <n> (out of scope)
- Dropped paths: <paths or none>

## Findings

### F1 — <one-line title>
- Bot: <account> · tag `<tag>`
- Sites: `path/to/file.ts:120` (+3 more: :145, :201, :288) · comment id `<hash>`
- Says: <the bot claim, one sentence>
- State: live
- Fix: <the concrete edit, one or two sentences>
- Risk: low
- Status: proposed

### F2 — <one-line title>
- Bot: <account> · tag `<tag>`
- Sites: `path/to/other.ts:44` · comment id `<hash>`
- Says: <claim>
- State: wrong — <what the bot misread>
- Fix: none.
- Dismiss: `/aino <one or two sentences naming the code that disproves the claim>`
- Status: proposed

## Dismiss with `/aino` (needs owner approval)
| Finding | Comment | Draft reason |
|---|---|---|
| F2 | `other.ts:44` | Guard on line 41 returns early, so line 44 cannot deref null |
| F5 | `gen/api.ts:9` | Generated by `pnpm codegen`, listed in `.prettierignore` |

## Needs the owner
| Finding | Comment | Why |
|---|---|---|
| F7 | `db.ts:88` | Bot is right. Fix changes the public signature |

## Verification plan
- <the repo commands that must pass before the amend>
```

## Rules for the report

- One finding per rule, not one per line. The site list carries the count.
- Quote the bot claim in your own words, in one sentence. Do not paste the whole comment.
- A finding with no fix still appears, with the reason. That is half the value of the audit.
- Never write `Status: done` before Phase 6 runs, or `Status: dismissed` before Phase 8 runs.
- Every `/aino` draft carries its evidence in the draft text. A draft without evidence is
  not ready to post.
